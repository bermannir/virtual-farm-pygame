# My Virtual Farm 

A rich, interactive 2D farming simulation game built entirely in Python using the Pygame library. 

## Features
* **Dynamic Environments:** Explore the main farm world, a detailed house, and an interactive barn.
* **Procedural Animation:** Custom-built rendering for characters, featuring pendulum-based walking physics, dynamic hair movement, and layered rendering.
* **Advanced AI & Entities:** * Aquarium fish with hunting logic, food-sinking physics, and bounded collision.
  * Flocking chickens that react to scattered food using custom state machines.
* **Progression System:** Earn XP by feeding animals to level up and unlock new farm features.
* **Robust Audio System:** Independent Master and SFX volume controls, with contextual sound effects (UI, environment, animals).
* **Smart Collision:** Custom anti-stuck mechanics and hitboxes for seamless scene transitions.
